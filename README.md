# Ascend Prep

Premium multi-exam preparation platform prototype.

## Exam experiences
- PMP
- NCLEX-RN
- Police Sergeant
- USMLE Step 1 (coming soon)

## Stack
- React
- TypeScript
- Vite
- Lucide React
- Responsive custom CSS

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
